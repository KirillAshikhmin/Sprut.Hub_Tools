# Эталон

На что это должно быть похоже. Собрано со слов пользователя — не выдумано.

## Образец
- «Напиши новый сценарий аналогичный Свету по датчику движения» — сценарий
  `MotionLightAutomation` («💡 Автоматизация света по движению»): структура файла,
  стиль кода, состав опций, формат README.
- «Эталон есть» — тот же сценарий.

## Что берём из эталона дословно
- «нужно такое же поле - разрешение автоматики» — блок `РАЗРЕШЕНИЕ АВТОМАТИКИ`
  (`gateAutoSwitch`, `gateAutoSwitchInvert`, `gateBlocksManualInputs`).
- «и ручные входы» — блок `РУЧНЫЕ ВХОДЫ` (3 слота: выключатель, кнопка,
  счётчик импульсов, датчик открытия).
