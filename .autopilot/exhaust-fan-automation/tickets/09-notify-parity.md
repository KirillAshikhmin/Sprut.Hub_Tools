## Критерии приёмки

- [ ] Новая опция «Тихое уведомление» (Boolean, по умолчанию `false`) в блоке `УВЕДОМЛЕНИЯ`, двуязычные `name`/`desc`; при включении уходит `.silent(true)`
- [ ] Если среди каналов есть Telegram — сообщение формируется с разметкой, как в Battery: жирный заголовок, строки «влажность / цель / сколько работала», имя устройства и комната; иначе плоский текст одной строкой
- [ ] Распознавание Telegram-канала берётся из Battery по смыслу (префикс имени канала), а не по полному совпадению строки
- [ ] Значение по умолчанию у `Каналы уведомлений` остаётся пустым: пусто = все каналы. Battery по умолчанию ставит `Telegram_1`, но там уведомления включены сразу, а здесь опция по умолчанию выключена — навязывать канал не надо
- [ ] README: новая опция описана в «Параметрах сценария», в разделе про уведомления сказано, что текст для Telegram оформляется разметкой
- [ ] `spec.md` §8 и §10 дописаны под новую опцию (это делает оркестратор, не исполнитель)
