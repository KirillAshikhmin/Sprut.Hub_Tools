## Критерии приёмки

- [ ] Контрактный тест опций §10 знает `noRunWhilePresent` и `purgeMinutes` с их дефолтами
- [ ] Режим выключен → существующие утверждения не меняются; добавлен тест «режим выключен — включение по присутствию работает как раньше»
- [ ] Присутствие активно при включённом режиме → вытяжка не включается; работающая выключается
- [ ] Запрет сильнее влажности: `humidityStartsFan` + высокая влажность + присутствие → не включается
- [ ] Уход подтверждён → включение, ровно `purgeMinutes` работы, затем выключение — границы точные
- [ ] Короткий визит (меньше `onDelaySeconds`) → продувки нет
- [ ] Возврат во время продувки → выключение сразу, в том числе при ненулевом `minRunMinutes`
- [ ] `purgeMinutes` = 0 → продувки нет
- [ ] `preset.json` дополнен обеими опциями с дефолтами
- [ ] `.tests/SPEC.md` описывает режим и его приоритеты
