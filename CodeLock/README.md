# 🔐 Кодовый замок (CodeLock)

Логический сценарий Sprut.Hub. Разблокирует устройство после ввода кода нажатиями на выбранных кнопках:
открывает замок, снимает сигнализацию с охраны, включает выключатель, открывает ворота.

## Назначение и поведение

Логика применяется к целевому устройству, а кнопки выбираются в опциях. При запуске сценарий подписывается
на события выбранных кнопок и накапливает нажатия. Когда последовательность совпала с кодом — записывает
в характеристику устройства значение «разблокировать» и, если задана задержка, через неё возвращает прежнее состояние.

Тип нажатия (одиночное / двойное / долгое) определяет сам хаб — сценарий получает готовое событие
`ProgrammableSwitchEvent` и длительность не измеряет.

### Поддерживаемые устройства

| Сервис | Характеристика | Действие при верном коде |
|---|---|---|
| Замок (`LockMechanism`) | `LockTargetState` | Открыто |
| Сигнализация (`SecuritySystem`) | `SecuritySystemTargetState` | Выкл. (снята с охраны) |
| Выключатель / Лампа / Розетка | `On` | Включено |
| Ворота (`GarageDoorOpener`) | `TargetDoorState` | Открыто |

## Формат кода

Код — последовательность нажатий. Цифра задаёт кнопку, буква — тип нажатия:
`S` — одиночное, `D` — двойное, `L` — долгое. Регистр не важен.

- Цифра без буквы — **одиночное** нажатие.
- Буква без цифры — **кнопка 1**.
- Повторная буква подряд — новое нажатие на той же кнопке.
- Пробелы и разделители `, . - + _` необязательны и просто игнорируются.

| Код | Что нужно нажать |
|---|---|
| `12357` | одиночные нажатия кнопок 1, 2, 3, 5, 7 |
| `SSDL` | кнопка 1: одиночное, одиночное, двойное, долгое |
| `1S 2S 1D 2S` | 1 одиночное, 2 одиночное, 1 двойное, 2 одиночное |
| `0D9L` | 0 двойное, 9 долгое |

Максимум — 32 нажатия в коде.

## Опции

- **Код** — последовательность нажатий (см. выше).
- **Разрешить произвольные нажатия до и после кода** — режим проверки:

  | Кнопка ввода | Галка | Как проверяется код |
  |---|---|---|
  | не выбрана | вкл | сравниваются последние N нажатий — лишние нажатия перед кодом не мешают |
  | не выбрана | выкл | код должен начинать последовательность; ошибка блокирует ввод до паузы «Задержка на ввод» |
  | выбрана | вкл | по нажатию «Ввод» код ищется внутри набранного — лишние нажатия до и после не мешают |
  | выбрана | выкл | по нажатию «Ввод» набранное должно точно совпасть с кодом |

- **Кнопка 1 … Кнопка 9, Кнопка 0** — сервисы кнопок, соответствующие цифрам в коде. Заполняются только нужные.
- **Кнопка ввода** — необязательная кнопка подтверждения. Реагирует только на одиночное нажатие;
  двойное и долгое на ней игнорируются полностью.
- **Задержка на ввод, с** (0–300, по умолчанию 10) — максимальная пауза между нажатиями. Пауза больше
  сбрасывает набранное и снимает блокировку строгого режима. `0` — без ограничения.
- **Вернуть прежнее состояние через, с** (0–3600, по умолчанию 0) — автовозврат. `0` — не возвращать.
- **Отладочный лог** — подробный разбор нажатий в консоль сценария.

## Переменные

- `subscribed` — подписка на кнопки уже оформлена.
- `opts` — снимок опций последнего вызова `trigger`; из него работает обработчик нажатий.
- `code` — разобранный код; `null`, если настройки содержат ошибку.
- `buffer` — накопленные нажатия.
- `lastPressAt` — время последнего учтённого нажатия (для «Задержки на ввод»).
- `blocked` — строгий режим: ввод заблокирован до паузы.
- `restoreTask`, `restoreValue` — задача автовозврата и состояние, которое она вернёт.

Переменные сбрасываются при перезагрузке хаба: набранное теряется, подписка оформляется заново.

## Настройка в Sprut.Hub

1. Примените логику к замку, сигнализации, выключателю или воротам.
2. Введите код в поле **Код**.
3. Выберите кнопки в полях **Кнопка 1 … Кнопка 0** — ровно те цифры, что используются в коде.
4. При необходимости выберите **Кнопку ввода** и включите галку произвольных нажатий.
5. Сохраните сценарий. Смена кода и состава кнопок подхватывается сохранением, перезагрузка хаба не нужна.

Если настройки содержат ошибку, сценарий пишет её в лог и не реагирует на нажатия до исправления:

- код пуст или содержит посторонние символы;
- в коде больше 32 нажатий;
- код использует кнопку, поле которой не заполнено;
- одна и та же кнопка выбрана в нескольких полях (включая «Кнопку ввода»);
- строгий режим без кнопки ввода при «Задержке на ввод» `0` — блокировку после ошибки нечем снять.

## Ограничения и замечания

- Разделение нажатий на одиночные, двойные и долгие выполняет хаб. Если кнопка не отдаёт двойные и долгие
  события, коды с `D` и `L` работать не будут.
- Счётчика неудачных попыток и временной блокировки после серии ошибок нет. Единственный тормоз перебора —
  строгий режим: после ошибки нужно выждать паузу.
- В режиме произвольных нажатий длинная серия нажатий подряд теоретически может перебрать код.
- Автовозврат возвращает **то состояние, которое было до ввода кода**. Если устройство уже было разблокировано,
  возвращать нечего. Ручное управление устройством отменяет запланированный автовозврат.
- `ProgrammableSwitchEvent` — событийная характеристика: два одинаковых нажатия подряд считаются двумя событиями,
  поэтому коды вида `SS` работают.
